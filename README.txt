INSTALL
1. Upload ALL files together to the same HTTPS website folder.
2. Open index.html in Chrome on Android.
3. Use the browser menu and choose "Install app" / "Add to Home screen".
4. Open ASH TAXI once while online so the service worker can cache the app.
5. After that, the app can open and work offline.

IMPORTANT
Your rides, expenses and shifts are stored locally on the device/browser.
Keep using ASH's Backup/Restore feature for important records.
